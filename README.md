# SGWEN XVI Links

Link tree for the Scouts & Guides of Wadi El-Nil (SGWEN XVI).

Live: https://sgwen-xvi-links.vercel.app
QR code: [`public/qr-code.png`](public/qr-code.png) / [`public/qr-code.svg`](public/qr-code.svg)

## Edit links
Add or change a line in the `links` list in `src/App.tsx`.

## Run / deploy
```bash
npm install
npm run dev
npx vercel deploy --prod --yes --archive=tgz
```
